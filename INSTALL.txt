🛡️ PHISHGUARD AI - INSTALLATION GUIDE
=====================================

QUICK START (3 Steps):
----------------------

Step 1: GENERATE ICONS
   - Open "generate-icons.html" in Chrome
   - Click "Generate Icons" button
   - Right-click each icon → Save as:
     * icon16.png
     * icon48.png  
     * icon128.png
   - Save all three to the "icons" folder

Step 2: LOAD EXTENSION
   - Open Chrome
   - Type: chrome://extensions/
   - Turn ON "Developer mode" (top-right)
   - Click "Load unpacked"
   - Select the "phishguard-extension" folder
   - Done! Extension is now active

Step 3: TEST IT
   - Open "test-page.html" in Chrome
   - Click the PhishGuard icon in toolbar
   - See the scan results
